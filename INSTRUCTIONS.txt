OVERVIEW
--------
The project has two reconstruction paths:

  Path A  Depth Fusion  (fast, sensor-accurate geometry, recommended for MeshLab)
  Path B  Photometric   (DINO + NeRF-style volumetric training, for ablations)

Both produce PLY meshes and MP4 videos.  Run Path A first — it takes under
2 minutes.  Path B (full research run) takes 20-40 minutes on an RTX 3060 Ti.


PREREQUISITES
-------------
Hardware:
  - GPU with >= 6 GB VRAM recommended (RTX 3060 Ti / 3080 / A100 etc.)
  - CPU-only works but is ~10x slower (use --device cpu flags below)

Software (already installed in .venv):
  Python 3.10+, PyTorch 2.x, CUDA 12.x, timm, trimesh, imageio, moviepy,
  scipy, scikit-image, open3d, matplotlib, tensorboard

================================================================================
PATH A — DEPTH FUSION (fast, best geometry)
================================================================================

Step A1: Build the 3D voxel grid, mesh, and point cloud
---------------------------------------------------------
python scripts/depth_fusion.py \
    --data-folder dataset/plant_data \
    --plant-id 1 \
    --grid 96 \
    --near-mm 350 \
    --far-mm 1900 \
    --output-dir outputs/my_plant1

This produces:
  outputs/my_plant1/
    plant_mesh_colored.ply   <- open in MeshLab
    plant_pointcloud.ply     <- open in MeshLab
    sigma.npy                <- volumetric occupancy (96^3)
    color.npy                <- volumetric colour (96^3)

MeshLab tips:
  - File > Import Mesh > plant_mesh_colored.ply
  - Render > Shading > Vertex
  - View > Show Vertex Colour
  - Filters > Smoothing > Laplacian Smooth (optional, 2-3 iters)


Step A2: Post-process the mesh (smooth + clean)
-----------------------------------------------
python scripts/postprocess_mesh.py \
    --input  outputs/my_plant1/plant_mesh_colored.ply \
    --output outputs/my_plant1/plant_mesh_final.ply \
    --smooth-iters 5 \
    --min-component-ratio 0.01

(Removes small floating fragments, applies Laplacian smoothing, fills holes)


Step A3: Render the 360-degree orbit video
------------------------------------------
python scripts/render_video.py \
    --sigma  outputs/my_plant1/sigma.npy \
    --color  outputs/my_plant1/color.npy \
    --output outputs/my_plant1/orbit_360.mp4 \
    --frames 120 \
    --size   512 \
    --device cuda \
    --multi-elevation

This renders 3 passes (high, mid, low elevation) into one 12-second MP4.
Remove --multi-elevation to render a single-elevation orbit instead.


================================================================================
PATH B — PHOTOMETRIC PIPELINE (full DINO + volumetric training)
================================================================================

Step B1: Quick sanity check (< 2 minutes, CPU, no pretrained weights)
----------------------------------------------------------------------
python scripts/run_pipeline.py \
    --preset fast \
    --data-folder dataset/plant_data

Expected output in outputs/:
  stage_20_dino/        DINO feature files
  stage_40_vol_train/   volumetric checkpoints
  stage_60_refine/      plant_mesh.ply (rough)
  stage_70_eval/        metrics.csv + rendered images
  stage_80_biomass/     biomass_report.txt


Step B2: Full research run (GPU, pretrained DINO, best quality)
---------------------------------------------------------------
python scripts/run_pipeline.py \
    --preset research \
    --data-folder dataset/plant_data \
    --output-root outputs/research_plant1 \
    --device cuda

This runs 12 volumetric epochs + 4 refinement epochs on a 256^2 render target.
Expected time: ~25 minutes on RTX 3060 Ti.


Step B3: Extended high-quality run (24 epochs, depth supervision)
-----------------------------------------------------------------
python scripts/run_pipeline.py \
    --data-folder   dataset/plant_data \
    --output-root   outputs/research_hq \
    --device        cuda \
    --epochs        24 \
    --refine-epochs 6 \
    --render-size   256 \
    --pretrained \
    --freeze \
    --lambda-consistency 0.05 \
    --biomass-labels-csv dataset/biomass_labels.csv

Note: --biomass-labels-csv is optional.  If provided, the CSV must have:
    plant_id,biomass_g
    1,42.3
    2,38.7


Step B4: List all available presets
------------------------------------
python scripts/run_pipeline.py --list-presets

Available presets include:
  fast              CPU sanity check (epochs=0, random DINO)
  fast_gpu          Quick GPU check
  research          Full experiment (12 epochs, pretrained DINO, CUDA)
  research_light    Lighter GPU run (6 epochs)
  biomass_proxy     Full run + biomass stage
  biomass_proxy_cpu Biomass proxy on CPU only


================================================================================
ABLATION STUDIES (test all 6 hypotheses)
================================================================================

Run all ablations at once (A1-A6):
------------------------------------
python scripts/run_ablations.py \
    --data-folder dataset/plant_data \
    --output-root outputs/ablations

Results saved to: outputs/ablations/ablation_summary.csv

Run specific pair only (e.g., H5 — consistency loss):
------------------------------------------------------
python scripts/run_ablations.py \
    --presets ablation_consistency_on ablation_consistency_off \
    --data-folder dataset/plant_data \
    --output-root outputs/ablations


Ablation map (6 hypotheses, 12 runs total):
  A1  ablation_pretrain_on / off      H1: Pretrained DINO improves reconstruction
  A2  ablation_freeze_on  / off       H2: Frozen backbone retains transfer quality
  A3  ablation_refine_on  / off       H3: Cross-grounding refinement improves geometry
  A4  ablation_epochs_long / short    H4: More epochs improve volumetric supervision
  A5  ablation_consistency_on / off   H5: Multi-view consistency loss (RQ1)
  A6  ablation_depth_on   / off       H6: Depth-guided lifting improves geometry (RQ2)

================================================================================
TROUBLESHOOTING
================================================================================

CUDA out of memory:
  - Use --device cpu (slower but always works)
  - Reduce --render-size to 128 or 64
  - Use --preset fast_gpu (fewer epochs, smaller render)
  - For ablations: edit src/config/presets.yaml and set epochs: 4

depth_fusion.py not found:
  - The script is created by the pipeline.  If missing, run:
    python scripts/run_pipeline.py --preset fast --data-folder dataset/plant_data
  - The depth fusion logic is also inside scripts/run_pipeline.py automatically.

mesh is empty / very few vertices:
  - Adjust threshold: python scripts/export_mesh.py --thresh 0.15
  - Try --sigma-percentile 20 to auto-select threshold

Video is black / no content:
  - Try different near/far: render_video.py --near 0.3 --far 2.5
  - Check sigma.npy has non-zero values: python -c "import numpy as np; s=np.load('outputs/plant1/sigma.npy'); print(s.max())"

Low PSNR (< 10 dB) is expected with only 4 views.
  - Add more turntable angles (8-16) for better reconstruction.
  - The depth-fusion mesh (Path A) is the primary quality deliverable.
